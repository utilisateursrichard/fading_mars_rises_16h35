# 📊 API Smartschool — Résultats (Skore)

Ce document répertorie les endpoints de suivi des notes, évaluations et bulletins scolaires (module Skore / Résultats).

---

## 1. Accès au module

- **URL principale :** `GET /results` ou `GET /skore` (à confirmer via F12)
- **Module header :** `smsc-module: results` ou `skore`

---

## 2. Endpoints AJAX à découvrir (F12)

- Liste des périodes (Trimestre 1, 2, 3)
- Notes par matière et coefficients
- Moyennes de classe
